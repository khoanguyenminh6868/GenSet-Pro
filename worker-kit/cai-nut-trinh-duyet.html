Cài nút "GenBid tải HSMT"

1. Bật thanh dấu trang của Chrome/Edge: Ctrl+Shift+B.

2. Kéo nút xanh dưới đây thả lên thanh dấu trang:

GenBid tải HSMT

3. Mở một gói thầu trên muasamcong.mof.gov.vn (trang chi tiết thông báo mời thầu), đợi trang tải xong rồi bấm nút đó. Nút sẽ lưu file <mã TBMT>_danh-sach-file.txt và tải từng file qua VNeGP Client Agent vào thư mục Downloads.

4. Nếu nút báo không gọi được Agent, chạy GenBid-HSMT.cmd: script tự bật Agent và tải các file trong danh sách vào Downloads\GenBid-HSMT\<mã TBMT>\.

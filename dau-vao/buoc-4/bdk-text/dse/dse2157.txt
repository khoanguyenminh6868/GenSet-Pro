DSENet® Data Sheet

DSE2157 DSENet® Output Expansion Module

Part Number : 2157-01

Overview
The DSE2157 Output Expansion Module has been developed for use with a wide range of DSE products. The DSE2157 extends the host modules
output capabilities for increased application flexibility. This is achieved by providing an additional 4 normally open volt-free contacts and 4 changeover
volt-free contacts.

For enhanced communication with the host module, the DSE2157 features a DSENet® port for connection to a wide range of DSE products. A red
status LED is provided to easily identify when the DSE2157 is connected to a power source and communicating with the host controller.

Key Features
• 4 Normally Open Volt-Free Contacts
• 4 Changeover Volt-Free Contacts
• Status LED to Indicate Power On and Link Lost
• DSENet® Communication

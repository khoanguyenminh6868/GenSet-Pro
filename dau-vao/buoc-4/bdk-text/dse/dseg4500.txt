Overview
The DSEG4500 Compact Single Genset Controller and DSEG4501 Compact Single Genset Controller with RS485 are part of the next-generation
DSEG-Series platform, designed for versatility and performance. User-configurable for Remote Start (RS) or Automatic Mains (Utility) Failure (AMF)
applications, they offer a robust feature set tailored to single genset operations.

Selected features include real-time monitoring of generator and load power, engine speed, oil pressure, coolant temperature, frequency, voltage,
current, power, and fuel level. All critical data is displayed on a dedicated multi-line, text and icon high-resolution screen.

The DSEG4500 and DSEG4501 support both electronic J1939 (CAN) and non-electronic (alternator frequency sensing) engines. This makes them
compatible with a wide range of fuel types including diesel, gas, and petrol. A generous number of flexible inputs, outputs, and protection features
ensures adaptability for diverse applications. Electric engines allow for an enhanced monitoring of the DEF tank and configurable alarms determined by
the SCR Inducement Severity level. Non-electric engines allow for input recognition of EGR fault inducement severities.

Fully programmable via the DSE Configuration Suite software, the DSEG4500 and DSEG4501 deliver the renowned DSE easy setup experience,
providing seamless integration and control.

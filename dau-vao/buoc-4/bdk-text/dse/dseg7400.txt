DSEG7400 Advanced Single Genset Controller

Part Number: G7400-01

Overview
The DSEG7400 is a remote start controller and an auto mains (utility) failure controller suitable for a wide variety of single, diesel or gas, genset
applications. Monitoring an extensive number of engine parameters, the controller displays warnings, shutdown and engine status information on the
back-lit LCD screen, illuminated LEDs and remote PC. The DSEG7400 can also monitor the mains (utility) supply.

The controller includes USB, RS485 and Ethernet ports as well as dedicated DSENet® terminals for system expansion.The controller is compatible
with electronic (CAN) and non-electronic (magnetic pick-up/alternator sensing) engines and offers an extensive number of flexible inputs, outputs and
engine protections so the system can be easily adapted to meet the most demanding industry requirements.

The list of features includes enhanced event and performance monitoring, remote communications and PLC functionality. Dual mutual standby is
available using RS485 communications. This provides for a simpler and more convenient installation with more advanced features such as true hours
balancing.

The controller also features SNMP functionality for connection to SNMP systems and can be easily configured using the DSE Configuration Suite PC
software. Selected front panel editing is also available.

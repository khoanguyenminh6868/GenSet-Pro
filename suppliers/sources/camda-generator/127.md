What Is a 688 KVA Standby Diesel Generator?
A 688 KVA Standby Diesel Generator is an emergency backup power system that stays in standby mode until the main power supply fails. It does not run continuously. Instead, it monitors the electrical grid and activates automatically when an outage is detected.
Once the system detects a power failure, it starts within seconds and supplies electricity to the connected load through an Automatic Transfer Switch (ATS). When power returns, it switches back to the grid automatically.
At a power factor of 0.8, the generator delivers approximately 550 kW of usable output power.

How the System Works in Real Operation
The working principle is simple but very effective. The generator is always connected to an ATS system that monitors utility power in real time.
Normal condition: utility power supplies the load
Power failure detected: ATS sends start signal
Engine starts automatically
Voltage and frequency stabilize
Load transfers to generator
Power supply continues without interruption
When utility power returns, the system automatically switches back and the generator cools down before stopping. No manual action is needed.

the menu.
• Features: receive remote output signal from ATS and realize auto start and

• Auto Mains Failure controller, can realize further more can detect ATS and

• Automatic Parallel Control Panel usually adopting intelligent control module of

switch adopts electronic breaker or frame breaker, combined togethe rwith the
generator, which is very reliable. One generator, one panel. The panel can be
used both for single genset working or Gensets Parallel working. This kind of
panel also can be used to parallel generator when the capability of the power
plant needs to be enlarged in the future.

Manual and remote start
The DKG-116 is a low cost, comprehensive unit designed to start and stop a generating set both manually and remotely.
The unit is suitable for both gasoline and diesel gensets. The standard unit controls gasoline engines. Diesel engine control is selected with a wire jumper connection.
The manual control is made using RUN and STOP pushbuttons on the front panel. The remote control is made via REMOTE START input signal.
When the engine is running, the unit monitors fault conditions and shuts-down the engine automatically in the occurrence of an alarm.

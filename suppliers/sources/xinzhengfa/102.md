| | 潍坊柴油发电机组
| | 潍坊柴油发电机组 ，柴油机动力选用里卡多R系列发动机是同介大型企业潍坊柴油机厂与一英国合资生产，R4105、R6105，功率范围40KW-100KW， 潍坊柴油发电机组 质量稳定，价廉物美。潍柴6170系列柴油发动机是由国家大型企业潍坊柴油机厂生产，是潍柴20世纪90年代设计开发的新一代机型，设计中吸收了国外柴油机先进的设计思想， 潍坊柴油发电机组 采用先进的技术生产，其动力性、经济性和可靠性在同类柴油机产品中处于领先地位，是中档功率范围国产机中的首选产品。 潍坊柴油发电机组 特点： 发电机组采用山东潍坊潍柴动力股份有限公司柴油发动机为动力 机组性能稳定可靠 低油耗、低排放、低噪音 该柴油发电机组采用旋转式柴油、机油滤清器、干式空气滤清器 机组抗磨耐用、结构紧凑、操作方便

Configuration Options
Open Type
Open type generator sets are suitable for equipment rooms, dedicated generator houses and sites where ventilation, exhaust routing and acoustic treatment can be designed separately. This configuration is convenient for inspection, daily maintenance and integration with existing power rooms.
Silent Type
Silent type generator sets integrate acoustic enclosure design with the generator package. They are suitable for commercial facilities, farms, workshops, construction sites and outdoor standby power applications where noise control and weather protection are required.
Super Silent Type
Super silent type configurations provide a higher level of sound attenuation and enclosure design. They are suitable for projects with stricter noise requirements, including residential-adjacent areas, commercial buildings, hospitality facilities and other noise-sensitive environments.
Control System
LCD screen with key operation and multilingual display.
Local and remote start functions for flexible operation.
Engine and alternator parameter monitoring within the complete generator set.
Control and protection functions with alarm indication and event logs.
Multiple communication interfaces available according to project requirements.
User settings can be configured through panel operation or PC software, depending on the controller model.
ATS Optional
An ATS panel can be supplied for mains/generator applications. The ATS controller integrates measurement, display and control functions, and supports automatic transfer between mains and generator power. It is suitable for facilities that require quick restoration of power after a utility outage. Communication functions and specific ATS models are subject to the final quotation and project configuration.
SWT Paralleling System Optional
For projects that need power expansion or multi-unit operation, SWT can provide a paralleling system for generator-to-generator or generator-to-grid applications. The system can support automatic synchronizing, automatic start, automatic parallel operation and load-based unit management. Up to 32 units can be synchronized according to project design requirements.

FAQ
Can SWT provide both 50Hz and 60Hz Perkins series generator sets?
Yes. This product range includes 50Hz models for 1500r/min applications and 60Hz models for 1800r/min applications, with voltage options depending on the project region.
Can the generator sets be supplied with a silent canopy?
Yes. Open, silent and super silent configurations are available for different installation conditions and noise requirements.

ATS is generally provided as an optional configuration. The final scope should be confirmed according to the project power distribution design.
Can multiple units operate in parallel?
Yes. SWT can provide a paralleling system for multi-unit operation and future capacity expansion when required by the project.
Will the generator set be tested before delivery?
Yes. SWT performs factory inspection and load testing before delivery according to order and product configuration.
Can SWT customize the generator set for overseas projects?
Yes. SWT can match voltage, frequency, enclosure, controller, ATS and optional accessories according to regional standards and site requirements.

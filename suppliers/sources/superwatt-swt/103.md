SWT Perkins Series 160kW / 200kVA Diesel Generator Set
The SWT Perkins Series 160kW / 200kVA diesel generator set is designed for industrial, commercial and standby power applications. Powered by a Perkins 1206D-E70TTAG1 diesel engine and matched with a 160kW / 200kVA alternator, this generator set delivers stable power output, efficient fuel performance and flexible configuration options for different project environments.

Product Details
Perkins Series 160kW / 200kVA Diesel Generator Set
The standard configuration is suitable for factory backup power, construction site power, commercial facilities, telecom infrastructure, public facilities and emergency standby power supply. Open type, silent type and super silent type configurations are available according to noise control, installation space and project requirements.
Prime power: 160kW / 200kVA; standby power: 176kW / 220kVA.
Powered by Perkins 1206D-E70TTAG1 engine, 6-cylinder in-line, turbocharged and water-cooled.
50Hz, 1500r/min, 380/400/415V, 3-phase output.
Available in open type, silent type and super silent type configurations.
Standard SWT single-unit control system with LCD display, multilingual interface, protection functions and local/remote start.
Optional ATS panel and SWT synchronizing system for automatic transfer and multi-unit operation.
Each unit is factory tested at 0%, 25%, 50%, 75%, 100% and 110% load before delivery.

SWT Single-Unit Control System
The standard SWT control system provides reliable monitoring, operation and protection for single-unit applications. The controller supports LCD display, key operation, multilingual interface, engine and alternator parameter detection, event logs and local or remote start.

ATS System Optional
An ATS panel can be provided for automatic transfer between mains power and generator power. The ATS controller integrates measurement, display and control functions and can be used for mains-to-mains or mains-to-generator applications.
Microcomputer control with full digital technology
LCD display for ATS operating status and controller mode
Voltage and frequency measurement through LCD screen
Fast on-load switching between two power sources with switching time ≤80ms
Electrical and mechanical double interlock to prevent short circuit between two power sources
Suitable for automatic backup power applications
SWT Paralleling System Optional
For projects requiring larger capacity or redundancy, SWT can provide a paralleling system for genset-to-genset or genset-to-grid applications. The system supports automatic synchronization of up to 32 units and can automatically start, parallel, load share, unload and cool down units according to load demand and mains power status.
Supports genset-to-genset, genset-to-grid and paralleling with ATS applications
Automatic start and synchronization of multiple units
Load-based unit input and withdrawal to avoid high-power units operating at low load
PLC system and touch screen available upon customer request
Flexible expansion for future capacity increase
Chinese and English operating system with built-in fault detection

The SWT 1000kW / 1250kVA Cummins Series diesel generator set is designed for high-capacity industrial, commercial and critical standby power applications. Product Details
1000kW / 1250kVA Cummins Series Diesel Generator Set
This series is available in 50Hz and 60Hz configurations, with open type and 20-foot containerized enclosure options. It can be configured with ATS, remote monitoring, synchronizing system and other project-specific accessories according to site requirements.
1000kW / 1250kVA class diesel generator set for large-capacity standby and project power requirements.
Available in 50Hz and 60Hz configurations to match different regional power standards.
Integrated genset design including engine, alternator, chassis, control box, protection system and exhaust accessories.
Open type and 20-foot containerized enclosure options for different installation environments.
Standard factory load testing at 0%, 25%, 50%, 75%, 100% and 110% before delivery.
Optional ATS panel, synchronizing system, RS485 / Ethernet communication and cloud monitoring.
Suitable for data centers, factories, mining sites, oilfield projects, infrastructure and emergency backup power.

ATS Optional
An ATS panel can be supplied as an optional accessory for automatic transfer between mains power and generator power. The ATS controller integrates measurement, display and control functions, and is suitable for mains-to-mains or mains-to-generator applications.
Digital microcomputer control.
LCD display for ATS operating status and controller mode.
Voltage and frequency measurement.
Fast on-load switching between two power sources, with switching time up to ≤80ms depending on configuration.
Electrical and mechanical interlock design to prevent short circuit between two power sources.
SWT Synchronizing System Optional
For multi-unit power projects, SWT can provide a synchronizing system for genset-to-genset or genset-to-grid operation. The system can automatically start units, synchronize operation and adjust the number of running units according to load demand.
Supports automatic synchronizing of up to 32 generator sets.
Suitable for genset-to-genset, genset-to-grid and paralleling with ATS applications.
Can reduce inefficient operation of high-power units under low load conditions.
Supports future capacity expansion by adding additional generator sets.
PLC system, touchscreen and customized control logic are available according to project requirements.

FAQ
Q1: What is the standby power of this generator set?
A: The SC1250 / SC1250X series is designed as a 1000kW / 1250kVA class diesel generator set. The exact rating depends on frequency, voltage and engine matching.
Q2: Is this generator set available for both 50Hz and 60Hz markets?
A: Yes. 50Hz configurations are available with 380 / 400 / 415V output, and 60Hz configurations are available with 440V / 254V output.
Q3: Can SWT provide a containerized version?
A: Yes. Open type and 20-foot containerized enclosure options are available according to installation and transportation requirements.
Q4: Can this generator set work with ATS?
A: Yes. ATS can be supplied as an optional system for automatic transfer between mains power and generator power.
Q5: Can multiple units operate in parallel?
A: Yes. SWT can provide a synchronizing system for up to 32 generator sets, suitable for multi-unit power station applications.
Q6: What tests are carried out before delivery?
A: Each generator set passes load tests at 0%, 25%, 50%, 75%, 100% and 110%, together with static and transient response tests and inspection of protection devices and control systems.
Q7: What applications is this generator set suitable for?
A: It is suitable for data centers, industrial plants, mining projects, oilfield projects, infrastructure, commercial buildings and emergency standby power applications.
Q8: Can the configuration be customized?
A: Yes. SWT can customize voltage, frequency, enclosure, fuel system, ATS, synchronizing system, communication modules and monitoring options according to project needs.

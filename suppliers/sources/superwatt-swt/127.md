SWT Perkins Series 200kW / 250kVA Diesel Generator Set
The SWT Perkins Series 200kW / 250kVA diesel generator set is designed for reliable standby and prime power applications. As a complete generator set manufacturer and system integrator, SWT provides the complete genset package including engine and alternator matching, base frame integration, control system, protection devices, enclosure options, factory testing and project-based configuration.

Product Details
Perkins Series 200kW / 250kVA Diesel Generator Set
This series covers 50Hz and 60Hz configurations. The 50Hz SP250 configuration provides 184kW / 230kVA prime power and 200kW / 250kVA standby power. The 60Hz SP250X configuration provides 180kW / 225kVA prime power and 200kW / 250kVA standby power. Open type, silent type and super silent configurations are available for different installation and noise-control requirements.
200kW / 250kVA standby power rating for industrial, commercial and emergency power applications.
50Hz and 60Hz configurations available for different regional power requirements.
Open type, silent type and super silent configurations available.
Integrated SWT control system with monitoring, protection, local/remote start and event logging.
ATS panel and synchronizing system available for automatic power transfer and multi-unit operation.
Factory load testing before delivery to verify performance, protection and control functions.
Suitable for factories, construction sites, telecom facilities, commercial buildings, rental power and emergency standby power.

Power Rating Description
| Rating | Description
| Prime Power (PRP) | Suitable for continuous operation under variable load conditions. 10% overload is allowed for 1 hour in every 12 hours.
| Standby Power (ESP) | Designed for emergency standby use at an average load rate of 80%, for no more than 500 hours per year. No overload is allowed.
Factory Testing
Each generator set is tested before delivery. The test process includes 0%, 25%, 50%, 75%, 100% and 110% load tests, as well as static and transient response checks. Protection devices and control systems are also inspected before the generator set leaves the factory.

ATS System Optional
An ATS panel can be provided for mains/generator or mains/mains automatic transfer applications. The ATS controller integrates measurement, display and control functions, enabling automatic switching between power sources when required.

Fast on-load switching of two power sources, with switching time up to ≤80ms depending on configuration
Electrical and mechanical interlock design to help prevent short circuit between two power sources

FAQ
What is the standby power of this generator set?
The SP250 and SP250X configurations both provide 200kW / 250kVA standby power.
What is the prime power?
The 50Hz SP250 configuration provides 184kW / 230kVA prime power. The 60Hz SP250X configuration provides 180kW / 225kVA prime power.
Is this generator set available for both 50Hz and 60Hz markets?
Yes. SP250 is the 50Hz configuration, while SP250X is the 60Hz configuration.
What voltage options are available?
The 50Hz configuration supports 380/400/415V. The 60Hz configuration in the technical files supports 220/127V.
Is a silent or super silent type available?
Yes. Open type, silent type and super silent type configurations are available.
Can this generator set work with ATS?
Yes. ATS can be supplied as an optional accessory for automatic transfer between mains and generator power.
Can multiple units work in parallel?
Yes. SWT can provide a paralleling system for genset-to-genset or genset-to-grid applications, supporting up to 32 units depending on project requirements.
What tests are performed before delivery?
Each generator set passes load testing at 0%, 25%, 50%, 75%, 100% and 110%, as well as control and protection system inspection before delivery.

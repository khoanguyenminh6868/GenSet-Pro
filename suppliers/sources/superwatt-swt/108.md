Cummins Series 300kW / 375kVA Diesel Generator Set
The SWT 300kW / 375kVA Cummins diesel generator set is designed for industrial, commercial and standby power applications where stable power output, reliable integration and flexible configuration are required. Built as a complete generator set solution, it integrates a diesel engine, alternator, common base frame, control system, protection devices and optional power transfer or paralleling equipment.

System Configuration
Power System Integration
SWT provides the generator set as a complete integrated power system. The standard scope can include the diesel engine, alternator, chassis, control box, single-unit controller, circuit breaker, industrial muffler, test report, certificate of quality, schematic diagram, installation manual and operation manual.
Control System
The standard SWT control system is designed for convenient generator operation and protection. It supports LCD display, key operation, multilingual display, control and protection functions, engine and alternator parameter detection, local and remote start, event logs and optional communication interfaces.
ATS Optional
An ATS panel can be provided as an optional accessory for automatic transfer between mains power and generator power. The ATS controller combines measurement, display and control functions, and supports fast on-load switching between two power sources. Communication functions can be configured according to project requirements.
SWT Paralleling System Optional
For larger or expandable power systems, SWT can provide a paralleling system for genset-to-genset, genset-to-grid or paralleling with ATS applications. The system can automatically start units, synchronise multiple generator sets, distribute load and determine the number of operating units according to actual load demand.

FAQ
Q: What is the standby power of this generator set?
A: The standby power is 300kW / 375kVA. It is suitable for emergency backup power applications where the generator operates when the main power supply fails.
Q: What is the prime power rating?
A: The prime power is 276kW / 341kVA under variable-load operation conditions.
Q: What voltage and frequency are available?
A: The standard configuration is 50Hz with 380V, 400V or 415V output. Other voltage requirements can be discussed according to the project.
Q: Is a silent type available?
A: Yes. SWT can provide open type, silent type and super silent type configurations for this model.
Q: Can this generator set work with an ATS panel?
A: Yes. An ATS panel is available for automatic transfer between mains power and generator power.
Q: Can multiple generator sets operate in parallel?
A: Yes. SWT can provide a paralleling system for multi-unit operation, load sharing and future capacity expansion.
Q: What tests are carried out before delivery?
A: Each unit is tested at 0%, 25%, 50%, 75%, 100% and 110% load, and the protection devices and control systems are inspected before shipment.
Q: What applications is this model suitable for?
A: It is suitable for factories, commercial buildings, construction sites, mining operations, public facilities, telecom infrastructure and emergency standby power projects.

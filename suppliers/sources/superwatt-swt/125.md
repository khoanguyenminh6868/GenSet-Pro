Perkins Series 1600kW / 2000kVA Diesel Generator Set
The SWT SP2200 diesel generator set is a high-power generator solution designed for industrial, commercial and critical standby power applications. With a prime power rating of 1600kW / 2000kVA and standby power of 1760kW / 2200kVA, it is suitable for large facilities and project sites requiring stable and dependable power output.

Power Rating Definition
| Rating Type | Description
| Prime Power (PRP) | The unit can run continuously for 24 hours under variable load. 10% overload is allowed for 1 hour every 12 hours.
| Standby Power (ESP) | Designed for emergency use at an average load rate of 80%, for no more than 500 hours per year. No overload is allowed.
Factory Testing
Before delivery, each generator set passes load tests at 0%, 25%, 50%, 75%, 100% and 110%, together with static and transient response checks. Protection devices and control systems are inspected before factory release.

FAQ
What is the prime power of the SWT SP2200 diesel generator set?
The prime power is 1600kW / 2000kVA, suitable for continuous operation under variable load conditions.
What is the standby power of this generator set?
The standby power is 1760kW / 2200kVA. Standby power is intended for emergency applications, and overload is not allowed.
What frequency and voltage options are available?
This configuration is designed for 50Hz operation with 380/400/415V voltage options.
Is a containerized configuration available?
Yes. In addition to open type configuration, a 40ft containerized silent type can be supplied according to project requirements.
Can the generator set work with ATS?
Yes. ATS can be configured for automatic transfer between mains power and generator power.
Can multiple units operate in parallel?
Yes. SWT can provide a paralleling system for set-to-set or set-to-grid applications, supporting automatic synchronization of up to 32 units.
What applications is this generator suitable for?
It is suitable for data centers, industrial plants, mining, oilfield, infrastructure projects, commercial buildings and emergency standby power systems.
Does SWT test the generator set before delivery?
Yes. Each unit is tested under multiple load levels, including 0%, 25%, 50%, 75%, 100% and 110%, with protection and control system inspection before delivery.

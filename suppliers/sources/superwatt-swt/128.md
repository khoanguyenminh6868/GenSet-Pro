Cummins Diesel Generator Sets
The SWT Cummins diesel generator series is designed for reliable industrial, commercial and project-based power supply. As a generator set manufacturer and power system integrator, SWT focuses on complete genset configuration, enclosure design, control integration, factory testing and project-specific adaptation rather than standalone engine promotion.
This product page covers 24kW to 440kW standby power models, with 50Hz and 60Hz options as well as open type, silent type and super silent configurations for different installation environments and noise-control requirements.

ATS Optional
An automatic transfer system can be configured for mains/mains or mains/generator applications. The ATS controller integrates measurement, display and control functions, and can support fast on-load switching, voltage/frequency monitoring and electrical/mechanical interlocking depending on the selected configuration.
SWT Paralleling System Optional
For multi-unit projects, SWT can provide a paralleling system for genset-to-genset, genset-to-grid and paralleling-with-ATS applications. The system can synchronize up to 32 units automatically and adjust the number of operating units according to load demand, supporting capacity expansion and flexible project deployment.

FAQ
What power range does this Cummins series cover?
This page covers SWT Cummins diesel generator sets from 24kW to 440kW standby power, with both 50Hz and 60Hz models available.
Can SWT provide a silent configuration?
Yes. Open type, silent type and super silent type configurations are available. The final enclosure design can be selected according to installation space, ventilation and noise-control requirements.
Can these generator sets work with ATS?
Yes. ATS can be supplied as an optional configuration for automatic switching between mains and generator power.
Can multiple units operate in parallel?
Yes. SWT can provide a paralleling system for multi-unit synchronization and load-based unit management.
Can the generator be customized for a specific project?
Yes. SWT can customize voltage, control system, enclosure, fuel system, monitoring and other options according to project requirements.

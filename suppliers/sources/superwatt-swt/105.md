Yuchai Series 500kW / 625kVA Diesel Generator Set
The SWT 500kW / 625kVA Yuchai diesel generator set is designed for reliable prime and standby power applications. Powered by a Yuchai YC6TD840-D31 diesel engine and matched with a high-performance alternator, this generator set delivers stable power output, strong load adaptability and flexible configuration options for industrial and commercial projects.

Product Details
500kW / 625kVA Yuchai Diesel Generator Set
With 50Hz operation, 1500r/min rated speed and 380/400/415V voltage options, the SY688 generator set can be used in factories, construction sites, mining projects, oilfield facilities, commercial buildings, infrastructure projects and emergency backup power systems.
Key Highlights
500kW / 625kVA prime power and 550kW / 688kVA standby power.
Powered by Yuchai YC6TD840-D31 diesel engine with turbocharged aspiration and water cooling.
Electronic governor and electronic unit pump fuel supply system for stable engine operation.
Available in open type and silent type configurations.
Standard single-unit control system with LCD display, multilingual interface, protection functions and local/remote start.
Optional ATS panel for automatic transfer between mains and generator power.
Optional SWT paralleling system for multi-unit operation and future capacity expansion.
Each generator set is tested at 0%, 25%, 50%, 75%, 100% and 110% load before delivery.

FAQ
Q1: What is the prime power of this generator set?
A: The prime power is 500kW / 625kVA. It is suitable for continuous operation under variable load conditions.
Q2: What is the standby power of this generator set?
A: The standby power is 550kW / 688kVA. Standby power is designed for emergency use, and no overload is allowed.
Q3: What engine does this generator set use?
A: It is powered by a Yuchai YC6TD840-D31 diesel engine with turbocharged aspiration, water cooling, electronic governor and electronic unit pump fuel supply system.
Q4: What voltage and frequency are available?
A: The standard configuration is 50Hz, 1500r/min, with rated voltage options of 380V, 400V and 415V. Other requirements can be discussed according to the project.
Q5: Is a silent type available?
A: Yes. The silent type configuration is available. According to the specification, the silent type size is 4800 x 1500 x 2240 mm, with a weight of 6075 kg.
Q6: Can this generator set work with ATS?
A: Yes. An ATS panel is available as an optional accessory for automatic transfer between mains power and generator power.
Q7: Can multiple units operate in parallel?
A: Yes. SWT can provide an optional paralleling system for genset-to-genset or genset-to-grid applications, supporting automatic synchronising of up to 32 units.
Q8: What tests are carried out before delivery?
A: Each generator set passes load tests at 0%, 25%, 50%, 75%, 100% and 110%, as well as inspection of protection devices and control systems before delivery.
Q9: What applications is this 500kW diesel generator suitable for?
A: It is suitable for factories, construction sites, mining projects, oilfield facilities, commercial buildings, data centers, telecom stations and emergency backup power applications.
Q10: What optional accessories can be selected?
A: Optional accessories include fuel tank, soundproof enclosure, containerized enclosure, trailer, ATS panel, synchronising system, RS485 communication, Ethernet communication, cloud monitoring and spare parts.

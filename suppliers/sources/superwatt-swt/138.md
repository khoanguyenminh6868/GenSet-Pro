Product Details
SC2500 Cummins Series Diesel Generator Set
This product page covers the 50Hz SC2500 configuration with Cummins QSK60 series engine options, including QSK60-G8, QSK60-G13 and QSK60-G21. FAQ
Q1: What is the prime power of the SC2500 diesel generator set?
A: The SC2500 series can be configured with 1600kW / 2000kVA or 1800kW / 2250kVA prime power, depending on the selected QSK60 configuration.
Q2: What is the standby power of this generator set?
A: The standby power is 2000kW / 2500kVA.
Q3: What frequency and voltage are available for this model?
A: The configuration in this product page is 50Hz, 1500r/min, with 380V / 400V / 415V rated voltage options.
Q4: Is a containerized version available?
A: Yes. The SC2500 can be supplied in a 40-foot containerized configuration for project sites requiring easier deployment, environmental protection or noise control.
Q5: Can this generator set work with an ATS panel?
A: Yes. ATS can be provided for automatic transfer between mains power and generator power.
Q6: Can multiple units run in parallel?
A: Yes. SWT can provide a paralleling system for genset-to-genset, genset-to-grid or paralleling-with-ATS applications. The system can support automatic synchronizing of up to 32 units.
Q7: What applications is this generator suitable for?
A: It is suitable for data centers, industrial plants, mining sites, oilfield projects, power stations, EPC projects and other critical power applications.
Q8: What tests are carried out before delivery?
A: Each generator set passes load tests at 0%, 25%, 50%, 75%, 100% and 110%, as well as inspection of protection devices and control systems before delivery.

SWT Cummins Series 360kW / 450kVA Diesel Generator Set
The SWT 360kW / 450kVA Cummins diesel generator set is designed for reliable prime and standby power applications in industrial, commercial and critical power environments. Powered by a Cummins KTA19-G3 diesel engine and matched with a high-performance three-phase alternator, this generator set delivers stable output, efficient operation and flexible configuration options for different project requirements.

Control System
The standard SWT control system is designed for single-unit generator operation. It supports local and remote start, engine and alternator parameter detection, control and protection functions, event logs and multiple communication interfaces.
LCD screen with key operation
Multilingual display
Engine and alternator parameter detection
Local and remote start functions
Control and protection functions
Event logs with real-time clock
Multiple communication interfaces available
IP65 overall protection available according to configuration
ATS Optional
An ATS panel can be supplied for automatic transfer between mains power and generator power. The ATS controller combines measurement, display and control functions for mains-to-mains or mains-to-generator applications.
Microcomputer control and all-digital technology
LCD display for ATS status and operation mode
Voltage and frequency measurement through LCD display
Fast on-load switching of two power sources, with switching time <= 80 ms
Electrical and mechanical double interlock design to prevent short circuit between power sources
Communication function available with optional communication module
SWT Paralleling System Optional
For projects requiring multiple generator sets, the SWT paralleling system supports genset-to-genset and genset-to-grid applications. The system can synchronize up to 32 units automatically and can select the appropriate number of running units according to load demand.
Automatic start and automatic synchronizing operation
Supports genset-to-genset, genset-to-grid and paralleling with ATS
Can automatically add or remove units according to load demand
PLC system and touch screen available upon request
Built-in fault detection and Chinese/English operation interface
Convenient capacity expansion for future projects

FAQ
Q: What is the prime power of this generator set?
A: The prime power is 360kW / 450kVA. It is suitable for continuous operation under variable load conditions.
Q: What is the standby power of this generator set?
A: The standby power is 400kW / 500kVA. Standby power is intended for emergency use, with no overload allowed.
Q: What engine does this generator set use?
A: This generator set is powered by a Cummins KTA19-G3 diesel engine.
Q: What voltage and frequency are available?
A: The standard frequency is 50Hz, and the rated voltage can be 380V, 400V or 415V. Other voltage requirements can be customized according to project needs.
Q: Is a silent type available?
A: Yes. Open type, silent type and super silent configurations are available.
Q: Can this generator set work with an ATS panel?
A: Yes. An ATS panel is available as an optional accessory for automatic transfer between mains power and generator power.
Q: Can multiple units operate in parallel?
A: Yes. SWT can provide a paralleling system for genset-to-genset or genset-to-grid applications, supporting up to 32 units for automatic synchronization.
Q: What tests are carried out before delivery?
A: Each generator set passes load tests at 0%, 25%, 50%, 75%, 100% and 110%, as well as inspection of protection devices and control systems before delivery.
Q: What applications is this generator suitable for?
A: It is suitable for industrial plants, construction sites, mining projects, oilfield projects, commercial buildings, telecom stations, data centers and emergency backup power applications.

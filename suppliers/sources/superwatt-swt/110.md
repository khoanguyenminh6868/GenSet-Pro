Product Details
2000kW / 2500kVA Baudouin Diesel Generator Set
The SWT Baudouin Series 2000kW / 2500kVA diesel generator set is designed for large-scale industrial, commercial and critical standby power applications. Powered by a Baudouin diesel engine and matched with a high-performance alternator, this generator set delivers stable power output, reliable operation and flexible configuration options for demanding project environments.
The standard 50Hz model is suitable for 380V / 400V / 415V power systems, with open type and 40ft containerized silent type configurations available. A 60Hz configuration can also be customized for 440V / 460V / 480V applications according to project requirements.

Optional ATS System
An ATS panel is available as an optional accessory for automatic transfer between mains power and generator power. The ATS controller integrates measurement, display and control functions for mains/mains or mains/generator applications.
Microcomputer control with digital technology
LCD display of ATS operating status and controller mode
Voltage and frequency measurement
Fast on-load switching between two power sources, with switching time ≤80ms
Electrical and mechanical double interlock mechanism to prevent short circuit between power sources
Control power can be supplied by main or standby AC/DC power without additional control power supply

FAQ
Q1: What is the prime power of this Baudouin diesel generator set?
A: The prime power is 2000kW / 2500kVA. It is designed for continuous operation under variable load conditions.
Q2: What is the standby power of this generator set?
A: The standby power is 2200kW / 2750kVA. Standby power is suitable for emergency use and should not be overloaded.
Q3: What engine does this generator set use?
A: The standard 50Hz version is powered by a Baudouin 12M55G4D3/5 diesel engine.
Q4: What voltage and frequency are available?
A: The standard configuration is 50Hz with 380V / 400V / 415V output. A 60Hz configuration for 440V / 460V / 480V can be customized according to project requirements.
Q5: Is a containerized silent type available?
A: Yes. The generator set is available as an open type or a 40ft containerized silent type.
Q6: Can this generator set work with ATS?
A: Yes. An ATS panel can be configured to automatically switch between mains power and generator power.
Q7: Can multiple units work in parallel?
A: Yes. SWT can provide a paralleling system for multi-unit power projects. The system can automatically synchronize up to 32 units.
Q8: What applications is this 2000kW diesel generator suitable for?
A: It is suitable for data centers, industrial plants, mining sites, oilfields, hospitals, commercial facilities, infrastructure projects and large standby power systems.
Q9: What tests are carried out before delivery?
A: Each generator set is tested at 0%, 25%, 50%, 75%, 100% and 110% load, and the protection devices and control system are inspected before delivery.
Q10: Can SWT provide customized configurations?
A: Yes. SWT can provide customized voltage, enclosure, ATS, paralleling system, remote monitoring, fuel system and other project-specific configurations.

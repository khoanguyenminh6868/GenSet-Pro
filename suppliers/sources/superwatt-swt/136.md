SWT MTU SML Series Diesel Generator Sets
360kW-520kW Prime Power | 50Hz | 400/230V
The SWT MTU SML Series diesel generator sets are designed for industrial and commercial power applications that require stable output, reliable starting performance and flexible system integration. Covering 360kW to 520kW prime power at 50Hz, this series is suitable for standby power, continuous-duty support under variable load, and project-based power supply where a compact high-power genset solution is required.

Control System
The SWT single-unit control system provides a user-friendly operating interface and essential genset monitoring functions. It supports LCD display, key operation, multilingual display, generator parameter detection, engine parameter detection, local and remote start, event logs and protection functions.
Automatic/manual start and stop operation.
Voltage, current and operating status monitoring.
Alarm lamps and event logging for maintenance reference.
Configurable parameters through panel operation or PC software.
Multiple communication interface options available according to project needs.
ATS Optional
An ATS panel can be supplied as an optional configuration for mains-to-generator or mains-to-mains automatic transfer applications. The ATS controller integrates measurement, display and control functions, and supports automatic switching between two power sources. The reference switching time is up to 80ms under the stated ATS configuration.
SWT Paralleling System Optional
For projects requiring multiple units or generator-to-grid operation, SWT can provide a paralleling system for set-to-set or set-to-grid applications. The system can synchronize up to 32 units automatically, support automatic start and parallel operation, and manage the number of running units according to load demand.
Suitable for genset-to-genset, genset-to-grid and paralleling-with-ATS applications.
Can help avoid inefficient operation of high-power units under small load.
Flexible expansion by adding additional gensets according to future capacity needs.
PLC system and touch screen options can be customized according to project requirements.

FAQ
What is the power range of the SWT MTU SML Series?
This series covers 360kW / 450kVA to 520kW / 650kVA prime power at 50Hz.
Can the generator set be supplied as a silent type?
Yes. Open type and silent type configurations are available. The final acoustic design should be confirmed according to site requirements.
Is ATS available for this series?
Yes. ATS is available as an optional configuration for automatic transfer between mains and generator power.
Can multiple units operate in parallel?
Yes. SWT can provide a paralleling system for set-to-set or set-to-grid applications, with up to 32 units synchronized automatically according to project requirements.
What should be confirmed before ordering?
Project voltage, frequency, load profile, installation environment, noise requirement, fuel system, control logic, ATS/paralleling requirement and local compliance requirements should be confirmed before final quotation.

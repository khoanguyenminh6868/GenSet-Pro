Control System
The standard SWT control system is designed for single-unit operation, monitoring and protection. It supports LCD screen operation, multilingual display, local and remote start, parameter monitoring, event logs and multiple communication interface options.
The controller can monitor key generator set parameters, support auto/manual operation modes and provide alarm indication for safer and more convenient daily operation.
ATS Optional
An ATS panel can be configured for mains/generator applications. It supports automatic transfer between utility power and generator power, with controller-based measurement, display and control.
The supplied technical files describe ATS switching applications for mains/mains and mains/genset systems, including fast on-load switching and electrical/mechanical interlock protection.
SWT Paralleling System Optional
For larger power requirements, SWT can provide a paralleling system for genset-to-genset or genset-to-grid operation. Multiple generator sets can be synchronized automatically according to the load demand.
The system can help avoid running high-power units at low load, improve operating flexibility and make future capacity expansion more convenient.

FAQ
What power range does this Perkins series cover?
This page covers SWT Perkins series generator sets from 7.2kW to 203kW, including 50Hz and 60Hz configurations.
Can SWT provide both open and silent generator sets?
Yes. Depending on the model, open type, silent type and super silent type configurations are available.
Are single-phase models available?
Yes. Selected small-power models are available in single-phase versions, including 50Hz and 60Hz options.
Can these generator sets be used for standby power?
Yes. The range is suitable for standby power applications in commercial, residential, telecom, factory and project sites.

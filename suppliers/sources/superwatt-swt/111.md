Cummins QSK60 Series Diesel Generator Set
The SWT Cummins QSK60 Series diesel generator set is designed for high-capacity power applications requiring stable output, strong engine performance and flexible system configuration. Based on Cummins QSK60 engine platforms, this series covers SC2250 and SC2500 models with 50Hz operation, 1500r/min rated speed and 380/400/415V rated voltage. It is suitable for large industrial facilities, data centers, mining operations, oil and gas projects, EPC power packages and standby or prime power plant applications.

SWT Single-Unit Control System
The standard SWT control system is designed for reliable operation, monitoring and protection of the generator set. It supports local and remote start, engine and alternator parameter detection, event logging and multiple communication interfaces.
LCD screen with key operation and multilingual display.
Control and protection functions for the engine and alternator.
Local and remote start functions.
LED and LCD alarm indicators.
Voltage and current measurement.
Generator and mains circuit breaker control.
Preset automatic start/stop cycle.
USB parameter configuration via PC software.
Real-time clock for accurate event logging.
Optional communication interfaces for integration and monitoring.
ATS – Automatic Transfer System Optional
An ATS panel can be supplied for automatic switching between mains power and generator power. The ATS controller integrates measurement, display and control functions and is suitable for mains-to-mains or mains-to-generator applications.
Microcomputer control and all-digital technology.
LCD display for ATS operating status and controller mode.
Voltage and frequency measurement through LCD screen.
PC-level switch with electromagnetic drive structure.
Fast on-load switching between two power sources, with switching time up to ≤80ms according to system configuration.
Electrical and mechanical double interlock design to prevent short circuit between two power sources.
SWT Paralleling System Optional
For large power projects, SWT can provide paralleling systems for genset-to-genset, genset-to-grid and paralleling-with-ATS applications. The system can support automatic synchronizing of up to 32 units and can automatically start, parallel, load-share and stop units according to load demand.
Supports genset-to-genset and genset-to-grid paralleling.
Up to 32 units can synchronize automatically.
Load-based unit management helps avoid operating high-power units at low load.
PLC system, touch screen and international-brand controllers are available on request.
Fully automatic operation with Chinese and English operating system and built-in fault detection.
Convenient capacity expansion for future project growth.

FAQ
What is the prime power range of this Cummins QSK60 Series generator set?
Depending on the selected configuration, this series covers 1600kW / 2000kVA and 1800kW / 2250kVA prime power.
What is the standby power of the SC2500 model?
The SC2500 configuration provides up to 2000kW / 2500kVA standby power.
Which Cummins engine models are available?
Available QSK60 engine options include QSK60-G4, QSK60-G8, QSK60-G13 and QSK60-G21.
Is a 40ft containerized version available?
Yes. A 40ft containerized configuration is available for large project deployment and easier on-site installation.
Can this generator set work with ATS?
Yes. SWT can supply an ATS panel for automatic transfer between mains power and generator power.
Can multiple units operate in parallel?
Yes. SWT can provide a paralleling system that supports automatic synchronizing of up to 32 units, depending on project requirements.
What voltage and frequency are standard?
The standard configuration in this page is 50Hz, 1500r/min and 380/400/415V. Other voltage requirements can be discussed according to project needs.
What tests are performed before delivery?
Each generator set passes 0%, 25%, 50%, 75%, 100% and 110% load tests, as well as static and transient response tests and protection/control system inspections.
What applications is this series suitable for?
It is suitable for data centers, industrial plants, mining projects, oil and gas facilities, EPC power stations, critical infrastructure and large standby power systems.
Can SWT provide customized solutions for special project requirements?
Yes. SWT can customize enclosure type, control system, paralleling system, ATS, remote monitoring, fuel system and project integration according to application requirements.

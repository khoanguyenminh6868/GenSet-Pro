SWT Yuchai Series Diesel Generator Sets
24kW-440kW Standby Power | 50Hz | Open & Silent Configurations
The SWT Yuchai Series diesel generator sets provide a flexible power range for commercial backup, industrial standby and project-based power supply applications. This series covers compact generator sets from 24kW prime power as well as larger 400kW prime power models, with open type and silent type configurations available according to site installation requirements.

Alternator and Output Configuration
The series is configured for three-phase output, Class H insulation, IP23 protection and low waveform distortion. Final alternator brand and model may be matched according to quotation, voltage requirement and project configuration. The SYM550 configuration references a Yuchai engine matched with a Mecc Alte alternator for the 400kW / 500kVA class.
Control System
The SWT single-unit control system provides a user-friendly interface for daily operation and protection. The control system supports LCD screen operation, multilingual display, local and remote start, engine and alternator parameter monitoring, event logs and communication interface options.
Automatic/manual start and stop operation through the control panel.
Voltage, current and operation status monitoring.
Alarm lamps and event logging for fault records and maintenance reference.
Parameter configuration through the panel or PC software.
Multiple communication interface options available according to project needs.
ATS Optional
An ATS panel can be supplied as an optional configuration for mains-to-generator or mains-to-mains automatic transfer. The ATS controller integrates measurement, display and automatic transfer control, with operating status shown through the LCD screen. The reference switching time can be up to 80ms under the stated ATS configuration.
SWT Paralleling System Optional
For multi-unit power systems, SWT can provide a paralleling solution for genset-to-genset, genset-to-grid or paralleling-with-ATS applications. The system can synchronize up to 32 units automatically, manage the number of running units according to load demand, and support future capacity expansion by adding additional generator sets.

FAQ
What power range does this Yuchai series cover?
This product page covers Yuchai-based SWT diesel generator sets from 24kW / 30kVA to 400kW / 500kVA prime power, with standby power up to 440kW / 550kVA.
Can these generator sets be supplied as silent type units?
Yes. The listed models include open type and silent type configurations. Final noise control requirements should be confirmed according to site conditions.
Are different voltage options available?
Yes. Depending on the configuration, voltage options include 380/400/415V and 400/230V. Final voltage should be confirmed before quotation.
Is ATS available?
Yes. ATS is available as an optional configuration for automatic transfer between mains and generator power.
Can multiple generator sets run in parallel?
Yes. SWT can provide a paralleling system for multi-unit operation and capacity expansion, with automatic synchronization according to project requirements.
What information should be confirmed before ordering?
Power rating, voltage, frequency, site altitude and temperature, load profile, enclosure type, fuel system, ATS/paralleling requirement and local compliance requirements should be confirmed before final quotation.

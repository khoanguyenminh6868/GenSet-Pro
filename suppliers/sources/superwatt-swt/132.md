Product Details
Yuchai Series Diesel Generator Sets
As a generator set manufacturer and system integrator, SWT focuses on the complete generator set solution, including system matching, base frame integration, cooling and exhaust arrangement, control system, protection functions, factory testing, silent or containerized configuration, ATS and paralleling options.
The series is suitable for customers who need reliable standby power, continuous project power, emergency backup power or multi-unit power plant solutions. Depending on the site conditions and installation requirements, the generator set can be supplied as open type, silent type or containerized silent type.
Power range: 440kW to 2200kW prime power.
Standby range: 484kW to 2400kW standby power.
50Hz configuration with 1500r/min rated speed.
Rated voltage options: 380V, 400V or 415V.
Open type, silent type and containerized configurations available.
Factory load testing before delivery, including 0%, 25%, 50%, 75%, 100% and 110% load tests.
Key Highlights
Complete generator set integration from SWT, with matched engine, alternator, control system, base frame and accessories.
Suitable for industrial facilities, data centers, mining sites, construction projects, commercial buildings and emergency backup systems.
Optional ATS system for automatic power transfer between mains and generator set.
Optional SWT paralleling system for multiple generator sets, grid paralleling and future capacity expansion.
Control system supports local and remote start, multilingual display, parameter monitoring, event logs and protection functions.
Silent and containerized options help reduce site noise and simplify outdoor installation.

Operating Conditions
Standard operating temperature: up to 40°C.
Standard altitude condition: up to 1000 meters above sea level.
Standard relative humidity: up to 60%.
When ambient temperature is higher than 40°C or altitude is higher than 1000 meters, power output should be corrected according to project conditions.
For high humidity, dusty, hot, cold, coastal or high-altitude applications, SWT can provide corresponding configuration adjustments according to site requirements.
Control System
The standard single-unit control system is designed for generator set monitoring, protection and easy operation. The actual controller model can be selected according to quotation and project requirements.
LCD screen with key operation.
Multilingual display and user-friendly interface.
Control and protection functions for generator set operation.
Engine and alternator parameter detection.
Local and remote start capability.
Multiple communication interfaces available.
Event logs for operation and fault tracking.
Configurable parameters through panel buttons or PC software, depending on controller selection.
ATS Optional
An ATS system can be supplied as an optional configuration for applications where automatic power transfer is required. It is suitable for mains-to-mains or mains-to-generator applications.
Automatic transfer control for mains/generator systems.
LCD display for operating status and controller mode.
Voltage and frequency measurement through the controller display.
Fast on-load switching with PC-level switch and electromagnetic driven structure.
Electrical and mechanical double interlock design to help prevent short circuit between two power sources.
SWT Paralleling System Optional
For larger power demand, staged investment or backup redundancy, SWT can provide a paralleling system for multiple generator sets. The system can be designed for genset-to-genset paralleling, gensets-to-grid paralleling, or paralleling with ATS.
Up to 32 generator sets can be synchronized automatically depending on system design.
Automatic start, synchronization, load sharing and stop sequence can be configured.
The system can automatically select the number of running generator sets according to load demand.
PLC system and touch screen options are available according to customer requirements.
Convenient for future capacity expansion by adding generator sets when required.

FAQ
What is the power range of the SWT Yuchai Series diesel generator sets?
This series covers 440kW to 2200kW prime power and 484kW to 2400kW standby power at 50Hz.
Can SWT provide silent or containerized generator sets?
Yes. Depending on the model and project requirements, SWT can provide open type, silent type or containerized silent type generator sets.
Can these generator sets be used for standby power?
Yes. The series is suitable for standby power in industrial, commercial, data center, hospital, mining and project applications.
Can multiple generator sets work together?
Yes. SWT can provide a paralleling system for multi-unit operation, load sharing, grid paralleling and future capacity expansion.
Is ATS available?
Yes. ATS can be supplied as an optional system for automatic transfer between mains and generator power.
Can the configuration be customized?
Yes. SWT can adjust configuration according to site environment, noise requirements, installation space, control requirements and power system design.

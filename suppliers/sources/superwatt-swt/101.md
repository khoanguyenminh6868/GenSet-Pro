300kW / 375kVA SDEC Diesel Generator Set
The SWT 300kW / 375kVA SDEC diesel generator set is designed for industrial, commercial and standby power applications. Powered by an SDEC 6ETAA11.8-G31 diesel engine and matched with a high-performance alternator, this generator set delivers stable power output, efficient fuel consumption and reliable operation for demanding project environments.
The generator set is available in both open type and silent type configurations, with optional ATS panel, soundproof enclosure, containerized enclosure, trailer and synchronising system. It is suitable for factories, construction sites, mining projects, oilfield operations, public facilities, telecom infrastructure and data center backup power systems.

Key Features
Reliable SDEC Engine: The generator set is powered by an SDEC 6ETAA11.8-G31 diesel engine featuring turbocharged aspiration, water cooling and electric control, supporting stable operation for industrial and standby power applications.
Stable Power Output: With 300kW / 375kVA prime power and 330kW / 413kVA standby power, the unit is suitable for both continuous variable-load operation and emergency backup applications.
Open Type and Silent Type Available: The open type configuration is suitable for equipment rooms and controlled installation environments, while the silent type configuration helps reduce operating noise for projects with noise-control requirements.
Factory Tested Before Delivery: Each generator set passes load tests at 0%, 25%, 50%, 75%, 100% and 110%, as well as inspection of protection devices and control systems before delivery.
Flexible Optional Configurations: ATS panel, soundproof enclosure, containerized enclosure, trailer, residential silencer, fuel tank, remote communication and synchronising system can be configured according to project requirements.
Easy Operation and Monitoring: The standard control system supports LCD display, multilingual interface, local and remote start, event logs, protection functions and multiple communication interfaces.
Applications
Industrial Plants and Factories: Provides reliable prime or standby power for manufacturing facilities, workshops and industrial production lines.
Construction Sites: Suitable for temporary and continuous power supply at infrastructure, building and engineering construction sites.
Mining and Remote Sites: Supports reliable power supply in remote areas where grid power is unavailable or unstable.
Oilfield and Energy Projects: Applicable to oilfield operations, energy facilities and other project sites requiring stable on-site power.
Commercial Buildings and Public Facilities: Can be used as backup power for office complexes, hotels, hospitals, public buildings and emergency facilities.
Telecom and Infrastructure Projects: Supports power supply for telecom stations, infrastructure projects and weak-grid areas.
Data Center Backup Power: Can serve as a standby power source for data centers and critical power systems requiring high reliability.
Standard Control System
LCD Display and Key Operation: The control system uses an LCD screen and key operation interface for intuitive monitoring and setting.
Multilingual Display: The interface supports multilingual display for easier use in international projects.
Control and Protection Functions: The system monitors engine and alternator parameters and provides control and protection functions for safe operation.
Local and Remote Start: The generator can be started locally or remotely depending on project configuration.
Event Logs and Communication Interfaces: Event logs and multiple communication interfaces support operation records and system integration.
ATS Panel Optional
Automatic Transfer Function: The ATS panel can automatically switch between mains power and generator power, improving power continuity during grid failure.
Fast Switching: The ATS uses a PC-level switch and electromagnetic driven structure, supporting fast on-load switching between two power sources.
Interlock Protection: Electrical and mechanical double interlock design helps prevent short-circuit risks between two power sources.
SWT Paralleling System Optional
Multi-unit Synchronising: The SWT paralleling system is designed for genset-to-genset and genset-to-grid applications, supporting automatic synchronising of up to 32 units.
Automatic Load Management: The system can automatically select the appropriate number of running units according to load demand, improving operating efficiency.
Flexible Expansion: Additional units can be added later for capacity expansion, making it suitable for projects with future power growth requirements.
Touch Screen and PLC Options: International-brand controllers, PLC system and touch screen can be configured upon customer request.

FAQ
Q: What is the prime power of this diesel generator set?
A: The prime power is 300kW / 375kVA. It is suitable for continuous operation under variable load conditions.
Q: What is the standby power of this generator set?
A: The standby power is 330kW / 413kVA. Standby power is designed for emergency use, and no overload is allowed.
Q: What engine does this 300kW generator set use?
A: This generator set is powered by an SDEC 6ETAA11.8-G31 diesel engine. The engine is turbocharged, water-cooled and electronically controlled.
Q: What voltage and frequency are available?
A: The standard frequency is 50Hz, and the rated voltage can be 380V, 400V or 415V. Other voltage requirements can be customized according to project needs.
Q: Is a silent type available?
A: Yes. Both open type and silent type configurations are available. The open type size is 3400 x 1160 x 1830 mm, and the silent type size is 4800 x 1500 x 2240 mm.
Q: Can this generator set work with an ATS panel?
A: Yes. An ATS panel is available as an optional accessory. It can automatically switch between mains power and generator power.
Q: Can multiple units operate in parallel?
A: Yes. SWT can provide a paralleling system for genset-to-genset or genset-to-grid applications. The system can support automatic synchronising of up to 32 units.
Q: What optional accessories are available?
A: Optional accessories include daily fuel tank, bulk fuel tank, residential silencer, power cable, battery charger, water jacket heater, soundproof enclosure, containerized enclosure, trailer, RS485 module, Ethernet communication, cloud monitor, ATS panel and synchronising system.
Q: What tests are carried out before delivery?
A: Each generator set passes load tests at 0%, 25%, 50%, 75%, 100% and 110%, as well as inspection of protection devices and control systems before delivery.
Q: What applications is this 300kW diesel generator suitable for?
A: It is suitable for industrial plants, commercial buildings, construction sites, mining projects, oilfield projects, telecom stations, public facilities, data centers and emergency backup power applications.

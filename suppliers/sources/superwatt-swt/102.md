The standard SWT single-unit control system provides LCD display, key operation, multilingual display, engine and alternator parameter detection, protection functions, local and remote start, event logs and multiple communication interfaces. ATS Optional
An ATS panel can be supplied as an optional accessory for mains-to-generator or mains-to-mains automatic transfer applications. The ATS controller integrates measurement, display and control functions. With PC-level switch and electromagnetic drive structure, the system can realize fast on-load switching between two power sources, with switching time up to <=80ms according to the specification.
SWT Paralleling System Optional
For projects requiring multiple generator sets, SWT can provide a paralleling system for genset-to-genset, genset-to-grid and paralleling with ATS applications. The system can support automatic synchronizing of up to 32 units, automatic start, automatic load sharing, automatic unit input or exit according to load demand, and automatic unloading and cooling down after mains power returns to normal.

FAQ
Q1: What is the prime power of the SK32.5 generator set?
A: The SK32.5 50Hz model provides 24kW / 30kVA prime power and 26kW / 32.5kVA standby power.
Q2: Is a 60Hz version available?
A: Yes. The SK40.4X 60Hz model provides 29.4kW / 37kVA prime power and 32.3kW / 40.4kVA standby power.
Q3: What engine does this generator set use?
A: The series is powered by a Kubota V3300-BG diesel engine, a naturally aspirated, water-cooled, four-cylinder in-line engine.
Q4: Can SWT provide single-phase versions?
A: Yes. SK32.5-1P is available for 50Hz 230V single-phase applications, and SK40.4X-1P is available for 60Hz 240V single-phase applications.
Q5: What enclosure types are available?
A: Open type, silent type and super-silent type configurations are available. Final dimensions and weights should be confirmed according to the selected configuration.
Q6: Can this generator work with ATS?
A: Yes. ATS is available as an optional accessory for automatic transfer between mains power and generator power.
Q7: What tests are carried out before delivery?
A: Each unit passes load tests at 0%, 25%, 50%, 75%, 100% and 110%, as well as inspection of protection devices and control systems before factory delivery.
Q8: What applications is this generator suitable for?
A: It is suitable for commercial backup power, farms, construction sites, telecom stations, emergency standby power, outdoor power supply and small industrial applications.

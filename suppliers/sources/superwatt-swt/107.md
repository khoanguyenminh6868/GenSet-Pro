SWT Weichai Series 300kW / 375kVA Diesel Generator Set
The SWT Weichai Series 300kW / 375kVA diesel generator set is designed as a reliable industrial power solution for standby and prime power applications. As a complete generator set manufacturer and system integrator, SWT provides the complete genset package including engine and alternator matching, base frame integration, control system, protection devices, enclosure options, factory testing and project-based configuration.

Product Details
Weichai Series 300kW / 375kVA Diesel Generator Set
This series is available in 50Hz and 60Hz configurations. The 50Hz SW400 configuration provides 300kW / 375kVA prime power and 320kW / 400kVA standby power. The 60Hz SW413X configuration provides 300kW / 375kVA prime power and 330kW / 413kVA standby power. Open type and silent type configurations are available to support different installation environments.
300kW / 375kVA prime power for industrial and commercial applications.
50Hz and 60Hz configurations available for different regional grid requirements.
Open type and silent type options for flexible installation.
Integrated SWT control system with monitoring, protection, local/remote start and event logging.
ATS panel and synchronizing system available for automatic power transfer and multi-unit operation.
Factory load testing before delivery to verify performance, protection and control functions.
Suitable for factories, construction sites, mining projects, oilfield facilities, commercial buildings and emergency backup power.

Factory Testing
Each generator set is tested before delivery. The test process includes 0%, 25%, 50%, 75%, 100% and 110% load tests, as well as static and transient response checks. Protection devices and control systems are also inspected before the generator set leaves the factory.

ATS System Optional
An ATS panel can be provided for mains/generator or mains/mains automatic transfer applications. The ATS controller integrates measurement, display and control functions, enabling automatic switching between power sources when required.
LCD display for ATS status and operation mode
Voltage and frequency measurement
Operating parameter settings through the controller
Fast on-load switching of two power sources, with switching time up to ≤80ms depending on configuration
Electrical and mechanical interlock design to help prevent short circuit between two power sources
SWT Paralleling System Optional
For larger power projects or systems requiring flexible capacity expansion, SWT can provide a paralleling system for genset-to-genset or genset-to-grid applications. The system can support automatic synchronizing of up to 32 units and can be configured with ATS according to project requirements.

FAQ
What is the prime power of this generator set?
The 50Hz and 60Hz configurations both provide 300kW / 375kVA prime power.
What is the standby power?
The 50Hz SW400 configuration provides 320kW / 400kVA standby power. The 60Hz SW413X configuration provides 330kW / 413kVA standby power.
Is this generator set available for both 50Hz and 60Hz markets?
Yes. The SW400 configuration is designed for 50Hz applications, while the SW413X configuration is designed for 60Hz applications.
What voltage options are available?
The 50Hz configuration supports 380/400/415V. The 60Hz configuration supports 440/460/480V.
Is a silent type available?
Yes. Open type and silent type configurations are available.
Can this generator set work with ATS?
Yes. ATS can be supplied as an optional accessory for automatic transfer between mains and generator power.
Can multiple units work in parallel?
Yes. SWT can provide a paralleling system for genset-to-genset or genset-to-grid applications, supporting up to 32 units depending on project requirements.
What tests are performed before delivery?
Each generator set passes load testing at 0%, 25%, 50%, 75%, 100% and 110%, as well as control and protection system inspection before delivery.

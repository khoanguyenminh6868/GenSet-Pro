Product Details
MTU Series 1800kW / 2250kVA Diesel Generator Set
The SWT SM2500 diesel generator set is a high-power generator solution designed for industrial power supply, critical standby power and large-scale project applications. With 1800kW / 2250kVA prime power and 2000kW / 2500kVA standby power, this generator set is suitable for facilities that require stable output, flexible system configuration and reliable operation under demanding project conditions. SWT provides the complete generator set integration, including engine and alternator matching, base frame, control system, cooling arrangement, exhaust system, sound attenuation or containerized enclosure, testing and project customization.
For projects requiring lower noise, outdoor installation or faster site deployment, the SM2500 can be supplied with a 40-foot containerized silent configuration. The system can also be combined with ATS panels, synchronizing systems, fuel systems, communication modules and remote monitoring according to project requirements.

ATS System Optional
An ATS panel can be provided as an optional configuration for applications requiring automatic transfer between mains power and generator power. The ATS controller integrates measurement, display and control functions, and is suitable for mains-to-mains or mains-to-generator systems.
Microcomputer control with digital technology.
LCD display for ATS operating status and controller mode.
Voltage and frequency measurement through the controller display.
Fast on-load switching of two power sources, with switching time up to 80ms depending on configuration.
Electrical and mechanical double interlock design to improve system safety.
SWT Paralleling System Optional
For power plant projects or larger capacity applications, SWT can provide a paralleling system for genset-to-genset or genset-to-grid operation. The system supports automatic start, synchronizing, load sharing and unit management according to load demand.
Supports automatic synchronizing of up to 32 generator sets.
Suitable for genset-to-genset, gensets-to-grid and paralleling with ATS applications.
Automatic operation and built-in fault detection.
The system can input or remove units according to load demand to avoid high-power units operating under low load.
Convenient for future capacity expansion by adding additional generator sets.

FAQ
What is the prime power of the SWT SM2500 diesel generator set?
The prime power is 1800kW / 2250kVA. It is suitable for continuous operation under variable load conditions according to PRP definition.
What is the standby power of this generator set?
The standby power is 2000kW / 2500kVA. Standby power is intended for emergency use and no overload is allowed.
Is a silent type available?
Yes. A 40-foot containerized silent configuration is available for projects requiring lower noise, outdoor installation or easier deployment.
What voltage and frequency does this model support?
The standard configuration is 50Hz with rated voltage options of 380V, 400V and 415V.
Can this generator set be used with an ATS panel?
Yes. ATS is available as an optional configuration for automatic transfer between mains power and generator power.
Can multiple SM2500 units operate in parallel?
Yes. SWT can provide a paralleling system for multiple generator sets. The system can support automatic synchronizing of up to 32 units.
What tests are carried out before delivery?
Each unit passes load testing at 0%, 25%, 50%, 75%, 100% and 110%, and the protection devices and control systems are inspected before delivery.
What applications is this generator set suitable for?
It is suitable for data centers, industrial plants, mining projects, oilfield projects, infrastructure projects, emergency backup power and remote prime power applications.

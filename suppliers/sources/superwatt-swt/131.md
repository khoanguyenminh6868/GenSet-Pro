Complete Genset System Configuration
The product range is configured as a complete generator set rather than a stand-alone engine product. The standard system includes engine, alternator, chassis, control box, controller for single unit, circuit breaker, industrial muffler, flange of muffler, bellow joint and shock absorber, with related technical documents supplied for installation and operation.
The alternator configuration supports H-class insulation and IP23 protection, while the control system provides LCD display, control and protection functions, parameter detection, local and remote start, event logs and optional communication interfaces.

LCD screen with key operation for convenient local control.

ATS Optional
An automatic transfer system can be configured for mains-to-mains or mains-to-generator applications. The ATS controller integrates measurement, display and control functions, and can show operating status and controller mode through the LCD screen.
Microcomputer control with digital technology.
LCD display for operating status, voltage and frequency data.
Fast on-load switching between two power sources, subject to selected ATS configuration.
Electrical and mechanical interlock design to help prevent short circuit between two power sources.
Suitable for standby power systems in commercial, industrial and infrastructure applications.
SWT Paralleling System Optional
For projects requiring higher capacity or redundancy, SWT can provide a synchronizing and paralleling system for genset-to-genset or genset-to-grid applications. The system can support automatic start, automatic paralleling, load-based unit input or removal, automatic unloading and cooling after mains recovery, and customized PLC control according to project requirements.
Up to 32 units can be configured for automatic synchronization depending on project design.
One-machine-one-screen operation enables both independent and parallel operation.
Automatic load-based unit management helps avoid low-load operation of large generator sets.
Convenient for future capacity expansion by adding additional units.

FAQ
Q: What capacity range does this product page cover?
A: This page covers SWT Cummins series diesel generator sets from 24kW standby power to 506kW standby power, including 50Hz and 60Hz models.
Q: Can the generator set be supplied in silent configuration?
A: Yes. Open type, silent type and super silent configurations are available according to the model and project requirements.
Q: Can SWT provide 50Hz and 60Hz solutions?
A: Yes. The SCM30 and SC550 models are available in 50Hz configurations, while SCM30X and SC633X are configured for 60Hz applications.
Q: Can these generator sets support ATS?
A: Yes. ATS can be configured for mains-to-generator or mains-to-mains applications, subject to project requirements and selected switchgear.
Q: Can multiple generator sets run in parallel?
A: Yes. SWT can provide a paralleling system for multi-unit operation, load sharing, automatic start and future expansion.
Q: Does SWT manufacture the engine?
A: No. SWT is a generator set manufacturer and power system integrator. The page focuses on the complete generator set, control system, enclosure, testing and project configuration.

DCEC CDLO160PSOA Diesel Generator Set
SinoGen CDLO160PSOA diesel generator set is the complete generator set manufactured by SinoGen. SinoGen CDLO160PSOA diesel generator set powered by DCEC 6CTA8.3 series diesel engine, comes with 50-degree aluminum radiator, coupled with Stamford alternator, controlled by Deepsea 6120 intelligent generator set controller.
The prime power for 50 Hz of SinoGen CDLO160PSOA diesel generator set (1500 RPM) is 160 kW.
The code C in the model name indicates that the engine brand of the unit is Cummins, the code D in the model name indicates that the fuel type is diesel, the code L in the model name indicates that the Land-used, the code O in the model name indicates that the open type, the code 160 in the model name indicates that the power is 160KW, and the code P in the model name indicates that the power type is the primary power. The code S in the model name indicates that the generator brand is Stamford, the code O in the model name indicates that the generator set has no ATS and no parallel function, and the code A in the model name indicates that the frequency of the generator set is 50hz.
As official exporting agent of DCEC, SinoGen is a professional power system solution provider, we provide one-stop power system solutions for customer from all over the world, from power system design to power system supply, from installation to commissioning, from after-sales services support to parts supply, SinoGen is your reliable power system partner that give you best value for money and reliable system solution.
Advantages of DCEC CDLO160PSOA Diesel Generator Set
1. Compact Overall Structure: Shangchai generator sets use a monolithic crankshaft, gate-type engine block, flat-cut connecting rod, and short piston, which are compact in shape and have strong adaptability for matching with other equipment.
2. Environmental Performance: The use of a new constricted combustion chamber, increased fuel injection pressure, and improved combustion process meet environmental standards. Exhaust pollutant emission values comply with the requirements of JB8891-1999, and noise levels meet the requirements of GB14097-1999 with a margin.
3. Lubrication and Cooling System Optimization: Reducing the number of external pipelines and components, using a brushless alternator as a whole, greatly improves the leakage situation and significantly enhances reliability.
4. High Altitude Operation Capability: Equipped with J98 and J114b types of waste gas turbochargers, it has strong high-altitude operation capabilities, with power loss below 3% when used in high-altitude areas above 5000m.
5. Adaptability to Harsh Environments: With high-vacuum exhaust ejection devices, three-stage cyclone German paper air filters, and low-temperature sintered ceramic piston rings, the diesel engine will not experience early wear when used in deserts or high-dust areas.
6. Electronic Fuel Injector Calibration: Uniformity of work among cylinders can be calibrated through electronic fuel injectors, with smooth torque output from the high-pressure fuel pump, low vibration, and low noise.

Overview
The DSE2131 DSENet® Ratiometric Input Expansion module is used in conjunction with supported DSENet® modules. The DSE2131 extends the host
modules input capabilities for increased application flexibility. This is achieved by providing an additional 10 ratiometric inputs which configured as
digital, resistive, 0 V to 10 V or 4 mA to 20 mA.
For enhanced communication with the host module, the DSE2131 features DSENet® for compatible devices. A red status LED is provided to easily
identify when the DSE2131 is connected to a power source and communicating with the host controller. The DSE2131 is designed to be mounted
within a control panel, either on the panel DIN rail utilising the integral mounts, or chassis mounted utilising the mounting holes.

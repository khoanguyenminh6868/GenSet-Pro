| DSEWebNet® Remote Monitoring | Software
Overview
DSEWebNet® is DSE’s cloud based remote monitoring software for DSE controllers. It has been developed to support single and multi-set generator
systems, and pump applications, The software includes geo-fencing, real time instrumentation & control, event log tables and automatic system alerts.
Alerts can be sent to multiple users by SMS and email, and reports can be sent via email. The software can be viewed using a laptop or desktop PC,
tablet or smart phone.

| DSEG8500 Standard Parallel Genset | Controller
Part Number: G8500-01
Overview
The DSEG8500 is a parallel genset controller with integral heater designed for complex paralleling applications. The DSEG8500 can be configured to
provide paralleling for up to 64 generators on a single site and provides a wide range of high-end features for multiple application environments. The
module is configurable for use as a single-set controller or multi-set controller, and can be used with the DSEG8600 configured as a multi-set or mains
(utility) controller.

|  |  |  | | # 高压发电机组

FRS-H高压系列柴油发电机组主要采用世界知名的康明斯、奔驰(MTU)、PERKINS油发动机，发电机采用MARATHON、STAMFORD、广州英格 (中英合资)、德科高压发电机。

其功率范围为 (常用功率):300KW~2400KW，电压等级范围为:3000 V 13800V。具有智能化、高强度、低噪音、低温启动能力强、耐用性好、操作方便、振动小、配套功能齐全等特点，特别适用于通信、数据中心、铁路、金融、电力、油田、工业、矿山、楼宇等场合使用。

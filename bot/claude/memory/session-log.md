## Bẫy chung
- index.html là một script lớn: hàm trùng tên thì hàm khai báo sau đè lên hàm trước, không báo lỗi (#282: loadLib mới đè loadLib cũ, Xem tệp hỏng). Trước khi thêm hàm, grep tên; thư viện CDN tải theo nhu cầu thêm vào `LIBS` của `loadLib(name)`. Thử trên bản chạy thử bằng UI thật, đừng chép code ra console.
- Back/quẹt trên điện thoại (Khoa 04/11: luôn về màn hình trước đó; PR #292, #294, #299): mỗi bước UI là một mục lịch sử `{gb:i}`, `navSync` chạy ngay trong click/keydown (listener trên window, #301: chạy trễ một nhịp thì ảnh chụp lúc quẹt là màn mới → nháy; thêm setTimeout dự phòng) so `navSnap()` (open, list, màn sup/bd/cat + chi tiết, dlg) với `navStack`: khác → pushState (ngay sau cú chạm; mục thêm không có cú chạm thì Chrome bỏ qua khi Back → rời trang về Google → 400), bằng bước trước → history.back(). popstate → `navRestore`. Mục 0 nằm sau màn chính (Back ở màn chính → forward). Màn hình/chi tiết mới trong modal phải thêm vào `navSnap`/`navRestore`; đổi URL phải `replaceState(history.state, …)`, không dùng null.
- Spinner chung (PR #307, Khoa 04/11: mọi thao tác chậm phải có spinner): `web/busy.js` nạp TRƯỚC supabase-js, bọc fetch + Response.json/text/blob; việc bắt đầu trong 1,5 s sau click/change/Enter/drop/paste (hoặc nối tiếp việc đang đếm) mà > 300 ms → viên "Đang xử lý…" đầu trang + `.is-busy` trên nút. Việc chậm không qua fetch (thư viện, dựng PDF, đọc tệp) thì bọc `window.genbidBusy(promise)`.
- Mọi truy vấn phân trang Supabase phải có `.order(...)` (#240: thiếu thì mất dòng).
- Khởi động lại lượt specs phải tắt cả Chrome hồ sơ `.genbid-browser-spec` (Chrome mồ côi đẩy CPU 100%). VNeGP Agent hay treo (400/timeout) → khởi động lại Agent.
- `wordText` (.doc qua Word COM) phải lưu format 2 + encoding 65001 (UTF-8); format 7 ra ANSI "?" trên nhiều .doc (sửa 03/11). `hsmtText` tải theo từng `hsmttext/<K>_<i>` (cả collection quá lớn → Vercel 502). Sửa genbid-sync.js bằng script ngoài: heredoc bash làm hỏng `\\`/`\n` — dùng Write tệp JSON + `rep.js`, hoặc Edit.
- Sửa GenBid-Bot.ps1 phải restart task ([[bot-restart-after-update]]); genbid-sync.js và config-bot.mjs chạy tiến trình mới mỗi lượt nên không cần.

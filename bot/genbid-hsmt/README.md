# HSMT worker kit

These are the tool scripts and instructions for the HSMT worker. They hold no token, state or tender data.
Since 2026-10-26 the Sync and file rounds run as code (genbid-sync.js, Node + Playwright) and the local bot GenBid-Bot.ps1 calls Claude only for Phân tích, Đối chiếu, Đối chiếu TLKT, Tạo bản tiếng Anh and Tạo HSDT tham khảo. See hsmt-worker.md.

To set up a new PC:
1. Install the official VNeGP Client Agent (C:\MPI\EGP-AGENT, port 1234), git and GitHub CLI, then run `gh auth login` (Publish-GenBidHsmt.ps1 uploads the tender files to GitHub Releases). Install Poppler for scanned PDFs: `winget install --id oschwartz10612.Poppler -e --scope user`, then restart the Claude app so its Read tool finds pdftoppm.
1b. Install Node.js 20+, then run `npm install` in C:ProjectsGenSet Progenbid-hsmt and `npx playwright-core install chromium` (or set GENBID_CHROME to a Chrome/Edge exe).
2. Copy the scripts into C:\Projects\GenSet Pro\genbid-hsmt\, and copy hsmt-worker.md to C:\Projects\GenSet Pro\.hsmt-worker.md.
3. Clone only the hsmt-inbox branch into C:\Projects\GenSet Pro\hsmt-inbox. Sign in to GitHub with a `git push --dry-run`, then set `git config user.name` and `git config user.email` inside the clone.
4. Create these local files by hand. Never commit them, because this repo is public:
   - C:\Projects\GenSet Pro\.genbid-ingest-token: the Vercel token, on one line.
   - C:\Projects\GenSet Pro\.hsmt-worker-state.json containing {"done": []}
5. Create a Claude Desktop scheduled task with TASK.md as the prompt, set its Schedule to Manual and turn it on. It runs only when Khoa clicks Run now, at any hour, with no time window. Click Run now once to approve its tools.
6. If the Windows user is not khoan, fix the Downloads path in hsmt-worker.md and TASK.md.7. The /hsmt skill is in skill\hsmt\SKILL.md: upload that SKILL.md in claude.ai Settings > Skills > Add > Upload skill (it replaces the old version; a zip made by PowerShell's Compress-Archive is rejected).

History of generator tenders (Khoa, 2026-11-02): `node genbid-sync.js history` searches "máy phát điện" on muasamcong without "chưa đóng thầu", keeps the tenders whose name is about a generator set (not a power plant's own generator), opens each opened tender's result page (or bid-opening minutes) and posts bidhist/<TBMT> (every lot's price, every bidder's bid, discount, result and reason, the won goods). .genbid-history.json remembers what was read: a tender with a final result is not read again, one with only the minutes is read again after a day. A scheduled Sync also runs a short round (up to 10 search pages, 80 tenders). For a long first round beside the bot use `--profile hist --full` (its own browser profile, no lock). The web shows it on the Nhà thầu screen and in Gợi ý giá đấu.
Config of past tenders (Khoa, 2026-11-02): `node genbid-sync.js history-config [--max N] [--key TBMT] [--keep]` reads the HSMT of bidhist tenders that name no power (name, lots, won goods): HSMT text on the web, else the webform Chương V, else the files named Chương V / Yêu cầu kỹ thuật / E-HSMT through the VNeGP Agent (archives unpacked with tar.exe; files copied to plain names because tar.exe cannot open Vietnamese paths), then posts bidhist config {kvas, text, src}. .genbid-histcfg.json remembers what was read. A scheduled Sync reads 15 more per round. Scanned PDFs give no text (not OCR'd).
OCR (Khoa, 2026-11-02): scanned PDF pages and pictures are read with Tesseract in Vietnamese. On the PC: `ocr-pdf.js` (tesseract.js from npm, no install with admin rights; the language data is cached in C:\Projects\GenSet Pro\.genbid-ocr, Poppler's pdftoppm renders the pages), used by fileText (HSDT, TLKT, templates, past tenders' config) and, before Phân tích / Đối chiếu / Tạo HSDT, by ocrHsmt for HSMT files that have no text on the web (adds their text to hsmttext). `node genbid-sync.js ocr-hsmt [--key TBMT]` does it for tenders already on the web. The hsmt-inbox Action (ingest.py) OCRs scanned pages with the Ubuntu tesseract-ocr-vie package. Render-GenBidScan.ps1 stays for pages OCR could not read.
Other formats (Khoa, 2026-11-02): fileText also reads .doc/.rtf (Word on this PC saves a text copy), .zip/.7z (tar.exe) and .rar (WinRAR's UnRAR.exe; tar.exe skips RAR5 entries with Vietnamese names), the documents inside read one by one. Before a request, ocrHsmt reads every HSMT file the web has no text for (PDF/pictures by OCR, .doc, .xlsx, archives) and marks the ones that gave nothing ocrTried. `node genbid-sync.js text --file <f>` prints what the bot reads from a file.
